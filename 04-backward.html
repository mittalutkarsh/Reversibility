04 / THE MATHS

The reversible backward pass

dL/dpl−1 += gl+1         the identity path — exact, no computation
dL/dpl   += 2h · vjp(f, pl, gl+1)   the path through the block gl+1 is the gradient arriving at state l+1. vjp is a vector-Jacobian product — what autograd computes when it pushes a gradient back through a function.

Page 03 showed the rule can be inverted. This page turns that into an actual backward pass that saves memory, and proves the gradients survive it.

One recomputation, two jobs

Walking down the stack at layer l, we recompute f(p[l]) once. That single evaluation does two separate things:

The forward pass saved only the final adjacent pair — no per-layer states. Everything else is rebuilt as the walk proceeds, and discarded again immediately.

Why one downward sweep is enough

Layer l maps (p[l-1], p[l]) → p[l+1], so it sends gradient to two states. Read the other way round: g[k] only ever receives from layer k and layer k+1.

The ordering works out

Walking down from l = L−1, layer k+1 is always processed before layer k. So by the time layer k is done, g[k] has received both of its contributions and is complete.

That is why a single sweep is exact rather than approximate. No state needs revisiting.

Worked, on two elements and two layers

Take f(x) = 0.5x + 1, so the Jacobian of f is 0.5·I and a vjp is just multiplication by 0.5. With h = 0.25, 2h = 0.5.

The spread across tensors is itself a check

Blocks 1 to 4 differ by about 1e−07. Block 0 differs by about 3e−06, thirty times more.

That is the right shape: block 0's input is the most-reconstructed state, so it accumulates the most error. A flat profile would have suggested the test was not exercising the reconstruction at all.

The cost

Every block runs twice — once forward, once during the backward reconstruction. That is roughly 2× the forward FLOPs instead of 1×.

Measured on the real model: 1.22× per step overall, because the backward pass already costs more than the forward one, so one extra forward evaluation is a smaller addition than it sounds.

Carry this forward: one recomputation per layer reconstructs the state below and supplies that layer's gradients, and because layer k+1 is always processed before layer k, a single downward sweep is exact.

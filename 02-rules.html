The three rules

baseline   xl+1 = xl + f(xl)
euler       pl+1 = pl + h·f(pl)
midpoint   pl+1 = pl−1 + 2h·f(pl) f is the whole transformer block — attention then feed-forward, with the layer norms inside. h is a fixed step size; we used 0.25. Only the combination rule differs between the three.

All three stacks use the same block. What changes is how the block's output is combined with what came before.

For the worked examples below, f is deliberately simple

We use f(x) = 0.5x + 1 so every number can be checked by eye. In the real model f is the full transformer block. The combination rules are exactly as they are in the code — only f is simplified.

Notice which state each one adds to

p2 is built from p0, not p1. p3 is built from p1, not p2. The block is evaluated at the state in between.

That one difference is the entire reason midpoint can be run backward and the other two cannot. The next page shows why.

Two chains, not one

Why the blend exists

Those two streams can drift apart, which is a known behaviour of this rule. The fix is to blend the final pair at readout: output = 0.5·p[L] + 0.5·p[L-1].

It costs nothing, because both states are already held. The 0.5 is the blend coefficient.

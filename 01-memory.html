01 / THE MATHS

Activation memory

memory for activations = batch × context × d_model × 34 bytes × layers 34 bytes per token per hidden unit is the measured cost of one transformer layer's stored activations in mixed precision, from Korthikanti et al. 2022 with FlashAttention.

Training has two passes. The forward pass computes the loss. The backward pass computes how each weight should change — and to do that it needs the inputs each layer saw.

Take a single multiplication y = W x. The gradient with respect to W is g · x, where g arrives from the layer above. You cannot compute it without x. So the forward pass stores x for every layer, and holds it until the backward pass reaches that layer.

This is the whole problem

The weights are stored once. The activations are stored per layer, per token, per sample in the batch. That product grows fast, and on a 16 GB machine it is what runs out.

What our model actually stores

8 × 1024 × 512 × 34 × 5 = 712,704,000 bytes = 0.71 GB batch 8, context 1024, d_model 512, 5 layers — the model in this experiment.

0.71 GB of layer activations. But the measured peak at batch 8 was 5.32 GB. The difference is almost entirely one tensor.

where the other 4.6 GB goes
the output head produces one score per vocabulary entry, per token:

  8 × 1024 × 8192 × 4 bytes   =  268 MB   for one copy

and three copies are live at once:
  forward output  +  saved log-softmax  +  gradient   =  805 MB

plus optimizer state, gradients, weights, and the allocator's own
working room.

That matters later: reversibility removes layer activations and does not touch the head. At larger batches the head dominates, so the fraction reversibility can remove shrinks — from 51.8% at batch 8 to 20.0% at batch 16.

Two ways out

Neither stores every layer
MethodWhat it storesWhat it costs
recomputationthe input of every group of layersrerun that group forward
reversibilitynothing per layer — only the final states rerun each layer once, backward

Recomputation still stores checkpoints, so its memory grows with depth. A reversible stack stores two states regardless of how many layers there are. That is the property worth having: activation memory becomes independent of depth.

Carry this forward: the backward pass needs each layer's input, storing them is what fills the card, and a reversible rule lets you recompute them instead of keeping them.
